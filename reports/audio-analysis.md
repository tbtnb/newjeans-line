# 音频与节奏谱说明

共 16 首完整人声歌曲，已排除所有 Instrumental。音频由本地无损文件转为 44.1kHz、双声道 MP3（当前曲库为 160kbps），移除封面、歌词、章节及来源元数据；保留标准 MP3 无缝播放编码头。转换不裁切歌曲，也不修改原文件。游戏时长取 MP3 解码样本长度，以避免编码填充导致结尾无法完成。

谱面方法：librosa 频谱包络和动态规划先生成节拍与乐句模板；独立 HPSS 只定位打击乐候选，再用约 1ms 的因果 PCM 能量窗寻找真实起音上升沿。已先用已知起音的合成样本校准，不能把频谱窗前沿当真实起音。仅把距强候选不超过 65ms、局部起音置信度至少 0.72 的转弯移动到候选；弱人声和持续音保留节拍估计，不强行吸附噪声。开头至少 2.25 秒，转弯间隔至少 315ms，尾音完整播放。

**精度边界：谱面仍是机器分析加编写模板，尚未进行真人听感验收。BPM、强拍和弱起音均为估计。四段中文空间名称与关卡设计一致；切换点在宽叙事窗口内寻找实际能量/频谱变化，再靠近已选节奏点，不声称是人工确认的主歌/副歌或小节线。修正后与检测器的接近程度是同源一致性指标，不等于独立的音乐性证明；完整前后分位数、未匹配弱段和早中晚残差见 rhythm-audit-final.json。**

复现：在独立 Python 虚拟环境安装 numpy、scipy、librosa，运行 `python scripts/prepare_audio.py --source <音乐文件夹>`；复用已交付音频可加 `--charts-only`；仅校准和修正现有谱面运行 `python scripts/rhythm_audit.py --cache <缓存目录> --refine`；需要本机 ffmpeg 与 ffprobe。

完整性：已核对 16 首源 FLAC 的原生 PCM 样本数和内嵌 MD5，均一致；所有输出 MP3 完整解码且无错误。源文件的附加尾部会触发 ffmpeg 的额外帧警告，但不影响已校验的完整音频样本，输出不含该尾部。

独立保留检测器（不参与吸附）的绝对残差中位数为 31.60→12.00ms，p90 为 76.79→73.94ms；±50ms 比例和 p95 没有同步提升，弱高频段尤其不确定。逐曲前后结果、早中晚数据和限制见 rhythm-audit-final.md/json。
