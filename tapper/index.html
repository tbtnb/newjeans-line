怎么用
  1. 选歌：上方选择 16 首里的一首（用的是游戏里的完整音频），或在 ⚙ 里用「本地音频…」打开自己的文件。播放时间下面显示已知的 BPM 和第一拍位置，可以在 ⚙ 里手动改，会画出节拍网格（粗线 = 小节，中线 = 拍，细线 = 八分）。
  2. 先校准：点顶部的「延迟」，跟着节拍器打 16 下。工具取中位数，得到你的输入延迟，之后每个点都会自动减去它（导出时原始时间也保留）。换设备或换耳机后请重新校准。
  3. 录制：把播放头放到想开始的地方（点时间轴顶部的刻度条），点「● 录制」，边听边打：空格 / 任意键 / 鼠标 / 手指点大按钮都可以。按 Esc 或「■」结束。时间来自音频输出时钟，不受画面卡顿影响。
  4. 双类型（可选）：在 ⚙ 里勾选后 F 键或按钮左半 = 鼓点，J 键或右半 = 人声。
  5. 慢速：0.75× / 0.5× 播放更容易跟准，时间会自动换算回原曲时间。⚙ 里勾选「保持音高」时音调不变（这时计时精度略低，建议最后用 1.0× 复查）。
  6. 编辑：时间轴上点空白处 = 加点，点标记 = 选中（Shift 多选），拖动标记 = 移动，Delete = 删除；勾「框选」或按住 Shift 拖动 = 范围选择；拖空白处 = 平移，滚轮 = 滚动，Ctrl+滚轮 / ＋－ = 缩放；方向键微调所选（±5 ms，按 Alt ±1 ms）。Ctrl+Z / Ctrl+Shift+Z 撤销重做。
  7. 重录一段：设 A、B（或框选后点「选区→AB」），点「↻ A–B」：这一段会循环播放，每打完一遍就用这一遍替换 A–B 内原来的点；满意了就停止。
  8. 复查：在 ⚙ 里勾「回放点击音」再播放，会在每个点上响一声（鼓点 / 人声音色不同）；「吸附预览」（⚙）显示每个点会吸到 1/8 或 1/16 网格的哪里，红色 = 离网格超过 60 ms，值得再看一眼。
  9. 导出：每首歌自动保存在本机浏览器。在 ⚙ 里「导出 JSON」下载文件，「复制 JSON」复制到剪贴板，发给制谱的人即可；也可以「导入 JSON」继续编辑。

延迟校准
