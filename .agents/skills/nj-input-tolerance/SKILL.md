# 输入、轨迹与容错

## 用户意图
用户认可普通路宽，后于23:10允许密集段局部加宽、短暂轻微出界先不死；2026-10-20 00:47明确要求恢复转弯居中开关，默认开启，覆盖此前禁止回中。开启沿用中心线路径；关闭使用当前位置自由转向，不擅自迁移其它15首。

## 实现约束
- `Route.freeTurns` 仅OMG关闭居中时启用；`denseAssist` 独立控制密集路宽，不得随居中关闭。设置在下次开始、复活或继续时应用，避免中途重解释历史轨迹。旧存档缺失centerAssist时默认true，显式false保留。`src/core/travel.ts` 的 `travelledSpans` 从真实点击时间积分出实际轨迹；`linePos`、`lineHeading`、拖尾、碰撞使用同一份轨迹。
- 居中关闭时，点击只改变此刻方向，不改变此刻坐标。早/晚点击产生的横向偏移要留在后续路段，不能插值回中心。
- 基础路面/碰撞共用 `readableRoadWidths`；密集段额外宽限使用 `edgeassist.ts`：至少3点连续间隔<=340ms，范围前后180ms；短暂出界距离<=0.35m、连续<=120ms可继续，回到路面才重置。明显/持续出界仍失败；不移动线头、镜头或谱面。
- 密集段目标宽度+0.20m，邻近平行路段保持至少0.18m可见地面间隔（含0.32m金边）；空间紧时实际只增约0.12m，绝不把相邻路粘合。普通段间隔仍至少0.30m。用细分扫掠防止低帧率穿墙；评分依旧可以按时间误差判断。
- OMG渲染用音频当前songTime；旧未来预测可能在点击到来后重写已经展示的位置，表现为线头/镜头一抽，不能误当相机平滑参数问题。
- 输入重复事件过滤保留；Safari时间戳回退扣除事件排队时长。晚判宽限只等候已发生但尚未派送的输入，不改变几何位置。
- 2026-10-20 01:08反馈开局误死/残线：检查点恢复须重置之前自由转向偏移（保留成绩和皇冠使用记录）；拖尾只绘制startTime之后，不能seek清空后又按历史turns重画。进入异步加载前立即隐藏旧线/碎片，ready才恢复线头。
- 音频play等待Safari resume必须带代次取消：stop/pause后旧promise不得重启旧音频；开始按钮单次在途锁，旧开始结果不能把新的loading/menu改成playing。开局手势120ms内的重复触点忽略，但必须截短到下一合法点击窗口之前。
- FX清理只能dispose临时glow/ring，不能误dispose钻石/皇冠；后者由seek复位。
- 重开要清擦边宽限计时、逻辑turns、碰撞检查时间、失败/完成计时器、输入去重状态，以及实际GPU拖尾。只清数组、没清网格是失败。

## 回归
- 居中关闭时，早120ms、晚120ms等代表输入：点击前后位置连续，方向立即变，之后偏移不被纠正。
- 离路时真实失败；同一次点击的抖动事件不消耗下一个弯。
- 失败→重开、完成→重开、检查点恢复、暂停继续；第0秒旧线不可见，后续线重新生长。
- 完美361次点击自动检查只是逻辑通关，不代表真实设备音画同步/手感通过。
- 入口：`tests/omg-playability.test.ts`、`tests/trail-reset.test.ts`。按本轮实际运行结果报告，不写死永远通过。

视觉连续性读 `../nj-line-skins/SKILL.md`；每轮修正同步 `../nj-skill-maintenance/SKILL.md`。
