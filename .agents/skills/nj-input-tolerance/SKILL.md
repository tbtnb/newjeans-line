# 输入、轨迹与容错

## 用户意图
用户认可当前路宽，要求早点或晚点在路面内能继续走；明确拒绝点击把线头吸回路中间、理想转角，或通过挪位置制造“命中”。这是OMG当前自由转向规则，不擅自迁移其它15首。

## 实现约束
- `Route.freeTurns` 当前只对OMG启用。`src/core/travel.ts` 的 `travelledSpans` 从真实点击时间积分出实际轨迹；`linePos`、`lineHeading`、拖尾、碰撞使用同一份轨迹。
- 点击只改变此刻方向，不改变此刻坐标。早/晚点击产生的横向偏移要留在后续路段，不能插值回中心。
- 可见路面宽度与碰撞边界一致（`readableRoadWidths`）；实际路径离开允许路面才失败。用细分扫掠防止低帧率穿墙；评分依旧可以按时间误差判断。
- OMG渲染用音频当前songTime；旧未来预测可能在点击到来后重写已经展示的位置，表现为线头/镜头一抽，不能误当相机平滑参数问题。
- 输入重复事件过滤保留；Safari时间戳回退扣除事件排队时长。晚判宽限只等候已发生但尚未派送的输入，不改变几何位置。
- 重开要清逻辑turns、碰撞检查时间、失败/完成计时器、输入去重状态，以及实际GPU拖尾。只清数组、没清网格是失败。

## 回归
- 早120ms、晚120ms等代表输入：点击前后位置连续，方向立即变，之后偏移不被纠正。
- 离路时真实失败；同一次点击的抖动事件不消耗下一个弯。
- 失败→重开、完成→重开、检查点恢复、暂停继续；第0秒旧线不可见，后续线重新生长。
- 完美361次点击自动检查只是逻辑通关，不代表真实设备音画同步/手感通过。
- 入口：`tests/omg-playability.test.ts`、`tests/trail-reset.test.ts`。按本轮实际运行结果报告，不写死永远通过。
