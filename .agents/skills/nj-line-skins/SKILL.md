# 连续转弯与皮肤

## 验收目标
- 一根线自然拐过去，不能像新画一段或独立盒子接上去。
- 转角无横断黑边、内部端面、缝隙、重叠顶面闪烁；纹理顺着转弯延续。
- 皮肤演示前端是实际3D模型/装饰；选择器图标可以是图片，展示线头不能用图标贴纸代替。

## 已证实的根因与方案
- 旧每段CreateBox各自UV从零开始；带彩边的皮肤会把边框横贴到拐角。仅把盒子错开避免共面，仍有拼接感。
- `src/render/trailmesh.ts` 将相连直段扫成一根立体带，拐角使用共同斜接截面；只有整根线的起止端有封面，转角内部没有端面。
- 顶面共享边界位置与UV；沿路径累计长度作纹理纵坐标，宽度作横坐标。左右转均检验；飞跃断开应保留，不跨空气补线。
- Babylon左手系三角绕序必须与声明法线一致，用 `VertexData.ComputeNormals` 核查顶面朝上，不能靠关闭背面剔除掩盖翻面。
- `LineSkinPlugin` 的连续带变体使用自定义 `trailUV`；普通独立线头/死亡碎片用非带状材质，避免缺属性。
- 线头与拖尾连接时隐藏重叠实体但保留3D装饰；不要为消缝放大头、叠共面或加黑描边。
- `src/render/skinpreview.ts` 复用同一几何/材质逻辑。结束预览停止渲染循环；重开清掉旧GPU数据。

## 性能与检查
- OMG仅保留线头后14秒的拖尾几何（大于路面9秒/相机后方窗口）；裁去整段前缀时保留累计路径长度arcOffset，避免纹理重置/跳动。不是按镜头中心强制移动线头。
- 临时glow/ring网格销毁时同时释放其独占材质，但不能销毁共享纹理；重开/unload也遵守。

- 正常生长只更新末端截面的顶点/UV，保留GPU缓冲；只在转弯、跳跃连接变化等拓扑改变时重建。
- `tests/trailmesh.test.ts`：左右转接缝位置/UV一致、没有内部封面、绕序正确、增量结果等于完整重建、跳跃仍断开。
- 实际GPU检查所有皮肤，重点铬面/胶片/牛仔：侧面、急转、短新段、暂停恢复、展示循环、死亡碎片。截图只能证明当帧，闪烁需连续观察。
- 图像证据可记录原始用户截图与版本；没有GPU能力时明确仅做了几何/构建检查，不宣称最终视觉通过。
