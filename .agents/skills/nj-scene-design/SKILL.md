# 场景设计（方案 C 模板）

## 本轮试玩覆盖旧编排
- 密集副歌的DROP可以保留布景表演，但不能自动恢复玩家路线的跳跃或下台阶；路线最新约束见 `nj-route-design`。
- 弹起兔子和兔子随从须让正面朝玩家接近时的相机。Blender正面−Y、运行时模板正面+Z，`place.ts` 用接近视角求yaw；检验法向与观察方向点积，并补实际镜头画面检查。
- 前景几何、台阶、上层走廊不得遮住后续路；并行四条路不能因宽度/边条连成难分辨的一片。
- 模型“进镜头才蹦出并卡顿”与设计中的弹出动画不同：前者是资源创建问题，提前准备见 `nj-performance`，不要删掉所有设计动画来掩盖它。

## 用户要的效果
- 华丽、密集、立体书感；同时手机流畅（预算见 nj-performance）。平淡、稀疏、“像平铺地毯上撒小物件”都会被否。
- 不重复克隆、不破碎、没有东西挡线头；改地图前先出设计稿（nj-design-sheets-codex）。
- 每轮都逐区和设计稿 key 图对照（`deliverables/omg-redesign/C/zones-*.jpg`，在 omg-design-v3 分支），交 `progress-morning.jpg`。

## 原作调研得出的原则（omg-design-v3 `levels-design/omg/redesign-v3/DESIGN.md` 第 1 节）
1. 低多边形“微缩模型”世界：轮廓清楚、平涂、有限色板、简单方向光。
2. 一关一个完整主题世界，所有物件服务主题。
3. 随乐段换景换色（检查点/段落时颜色、灯光、物件、氛围一起变）。
4. 路是世界的一部分（桥、栈道、书页条…）。
5. 布景动画 = 音乐可视化：drop 一个大动作，乐句中动作，拍子小动作（亮灯/轻跳）。
6. 光与雾把视线集中到路和线头；**路面永远最亮、最干净**。
7. 每区 3–5 色限定色板；区与区之间“颜色 + 地形 + 路面材质”三重变化。

## 方案 C 结构（omg-design-v3 `C/DESIGN.md`）
- 整关是一本立体书，每区 = 一章，区之间翻页转场。时间线：黎明薄雾 → 正午 → 深黄昏 → 夜（DROP① 45.4 s）→ 月夜 → 夕阳 → 星夜 → 嘉年华夜（DROP② 105.8 s，全关最华丽）→ 静夜 → 日出。
- 十区：z01 0–15.1 封面·晨光翻开｜z02 15.1–30.2 兔子村｜z03 30.2–45.4 纸页病房｜z04 45.4–60.5 弹出城堡之夜｜z05 60.5–75.6 月光湖纸船｜z06 75.6–90.7 电话花田｜z07 90.7–105.8 星空纸塔｜z08 105.8–121.0 爱心嘉年华｜z09 121.0–151.2 静夜森林｜z10 151.2–160.6 日出大团圆。
- 五层布景：地被（thin instance，不投影）｜中景道具 3–10 m｜地标/主件 10–25 m（每区 1–3 个，弹出动画，远处 LOD）｜天空/远景（billboard 或合并成远景片）｜小动画（粒子/实例，同屏上限）。
- 数据流：`zones_c.py`（omg-design-v3）→ `tools/omgc/make_spec.py` → `levels-src/omg/scene-c.json` → `src/render/scenec/place.ts`（确定性分块放置）→ `scenec.ts`。一切按路线时间 t 和左右侧相对放置，所以重新出谱后场景还能用。

## 书页台地（5d46e34，r10）和花圃（467d186，r11）
- 路两侧隆起台地：每段 1.6–3.8 s，高 1.3–3 m，宽 9–15 m；避开所有路、线头视线和书页展开；顶面 = 该区书页，边缘 = 合上的书的切口（封面边 + 页边，两档画质都有）。
- 装饰、主件、填充都站在台地上，**不跨边**（主件要么完全在台地上，要么台地在它周围断开）；跨边的物件吸附到台地上（r11）。
- 台地/页边是“一叠合上的书”（区封面色、白色页、下层书往外错一点），不是淡紫条纹（560cd78）。
- r11：台地顶铺花片、灌木、花圃、树、少量小房子；顶面轻微染色和 UV；台地脚软 AO；台地沿线卷起的页边 + 路口的书脊唇边。
- 开书前景（2947b43）：区边界（和 z09 区中）路旁的书页，外缘金边卷起，页块、书堆，合进 page-stack 网格（0 额外 draw）。

## 密度手段（按出现顺序）
- 3D 小套件替代平面贴片；连续中景簇；远环纸山 22–55 m（30b8e72）。
- 放置重试：落在别的路段上的点换地方再试（以前丢掉约 70% 中景 / 45% 地被，996a912）。`place.ts` 每件最多 6 次尝试。
- 簇团（森林团、树篱、松/山/房子簇），去掉碎点（78b8de5）。
- 'view' 层：在离流线有横向偏移的地方排行/成团，推出之字形（e228ad7）。
- 混合贴路排（每个成员是不同的设计件，2e1dd45）；贴路是按层开启的（`hug`，d2152da）。
- 画面填充网格：空格子补小混合团（532dca0）；廉价混合树林（每棵 150–300 三角）和小堆（v9b）。
- 净空：高物件离任何路 1.5 个路宽；低于 `groundMaxH` 的地被可以贴路边（`clear.groundMaxH` 在 make_spec 里设为 1.6）；树/山团高度上限约 6 m（彩色布景和主件占据高度）。

## 去重复（用户反馈后 v8–v10）
- 每实例色板变体（取设计稿色值、按色度匹配）+ 高度拉伸；布景按顺序取变体；排内交替种类、步进变体（e50622e）。
- 占用网格：装饰不穿装饰/布景；大件先放（e50622e）；随从也进占用网格（a917493）。
- clone pass：≥0.8 m 的中景件，7 m 内同种邻居不能用同一色板变体（7b768b0）。
- 混合堆的种类加变体（mushroom-group 7、firefly-lamp 7、lily-lamp 6、pull-tab 6、rock 6，c186149）。
- 验收：`node tools/qa/repcount.mjs <url> out.json` → 每区可见不同资产数、头部资产占比、克隆对（v10 起 0）。

## 夜景与光
- 夜区装饰不受雾，向区暖光提亮；合并的加色灯晕（996a912、bf905eb）。
- 不用 GlowLayer（会把所有 unlit 的自发光白材质当作发光：发白、draw 翻倍）；“bloom” = 合并发光网格里淡淡的 2.3× 光晕复制（6f4737f）。柔光晕不做 bloom 复制（过度绘制，8975a42）。
- 主件窗户发光（城堡/摩天轮/旋转木马常亮，其它主件夜里亮，a5e125b）。
- 天空带：白天/黄昏/暮色天空条（深度测试的 70 m 带，高主件站在它前面，e228ad7）；夜空条（月亮、星星、剪影天际线，4e08ca1）；`tools/omgc/sky_day.py`、`sky_strip.py`。

## 地面与远景（v4）
- Codex 画的分区地面贴图 + 地平线背景，无缝混合 WebP（3b21c5b；提示词 `deliverables/omg-c-paint/prompts.md`）。
- 世界空间 UV 地面块，4×4 矩形加抖动边缘淡出；书页按“最近的路”归属区，16 m 抖动混合（9e37d15）；页面需要 `hasVertexAlpha`（f8c9e89）。
- impostor 地毯：Blender 等距精灵（36°，平涂烘焙色，无描边）+ 图集，卡片面向镜头路径，近处按距离缩小（bfa501d、ad9f962）；impostor 不进近景带。

## 逐区打磨清单（每轮）
1. 用 zshots/play 在 Mac GPU 上取每区关键时刻（线头定位后的画面）。
2. `python3 tools/qa/progress-board.py <renders> <shots> out.jpg "<title>" z01 z04 ...` 和 key 图并排。
3. 对每区写：缺什么（立体感、主件大小/入画、天际线、地面颜色、密度），按优先级改 make_spec.py。
4. 跑 repcount（克隆对）、heroproj（主件入画）、trisweep（预算）、play --headlog（线头 42%）。
5. 发预览，交对比图，说清剩余差距。

## 交接时已知差距（v11）
z03 地面仍是橘粉色主导（台地顶要更绿、植物更密）；z08 旋转木马 53%、摩天轮 42% 入画；z05 船偏低、帆偏淡；台地顶色差太弱；卷页边/书脊只在截图尺寸检查过；天际线只有 key 的一半高；整体还不如 key 立体（没有靠近镜头的厚书页和大兔子）。
