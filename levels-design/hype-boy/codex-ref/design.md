# Hype Boy — Summer Pool Unfolding / 夏日心动展开

《New Jeans》首张 EP（2022）的蓝白兔子，变成漂浮在夏日运动场、泳池与屋顶之间的关卡。情绪是轻盈、期待、略带恍惚的心动；用空间的收紧与打开表现靠近某个人的感觉。

- `concept.png`：第一轮副歌泳池段的游戏内视角；单个珊瑚色方块、实体尾迹、连通窄路、兔子浮雕、场外表演与远处皇冠。无 UI 文字、点击标记或引导符号。
- `blueprint.png`：真正俯视的九区总图，含重复乐段、P1–P8 场景事件、E1 彩蛋、三处皇冠与升层剖面。白底钴蓝边为唯一可走主路；浅青池沿和场地装饰均不可走。
- 两张 PNG 均由图像生成制作并经过定向修改。蓝图为美术与空间参考，不是按比例施工图；微观转弯位置和帧级节拍仍需实际音轨对齐。

## 研究依据

经典《Dancing Line》以俯视斜角、简单几何、大块纯色和高辨识度实体线条组织画面。《The Piano》的琴键直接成为空间；《The Autumn》把道路嵌进季节景观；《The Desert》通过景物出现、结构打开与换色制造段落变化。这里沿用“音乐推动场景表演”的方法，保留窄路、方块、宝石和皇冠，不堆叠装饰。

《Hype Boy》的轻快律动、柔和音色和扬起的副歌适合“封闭通道 → 开阔泳池 → 空中终段”。歌词主题可概括为白日梦般的青春吸引；MV 的四个视角把人物关系汇到共同的派对语境。已查看运动场／红白球门、更衣柜／黄色篮球的发布剧照，并查看官网实际 EP 封面：靛蓝底、白色半色调兔子与下方 NWJNS 字样。兔子是 **2022 首张 EP** 的来源。

## 路线、镜头与乐句事件

全关保持世界坐标直角转弯，借长直道、不等长偏移、开放 U 形和收口通道区分段落。相机采用约 **52° 俯角、45° 平面斜角**的近正交视图。下表方向指镜头前瞻区域；镜头不随每次转弯猛转。

| 蓝图区 | 环境／路线构图 | 镜头前瞻与音乐同步事件（制作建议） |
|---|---|---|
| 01 Intro · L0 | 稀疏起步台、两次宽松转折；天空留白。 | 向北前瞻；P1 开头四拍口数依次抬起四片场外屋顶，随后稳定。 |
| 02 Verse 1 · L0 | 柜体收紧；一条长巷连接不等长短偏移。 | 保持近景、看清接下来三处弯；鼓组进入后柜体分组升起，避开转弯判定时刻。 |
| 03 Pre-chorus 1 · R1 | 长平台逐段错位上升，L0 → L1；围墙从包裹转为敞开。 | 镜头缓慢抬高并向右前瞻；P2 在人声抬升时墙片向外折，副歌前完整露出泳池。 |
| 04 Chorus 1 · L1 | 沿泳池左、下、右三侧走开放 U 形；长线条中留少量短转折。出口 CP1，再经 B1 平桥。 | 拉远约 15%，泳池与兔子同时入画；P3 副歌落点展开三块背景板，五色柱按人声问答做两组起伏。 |
| 05 Verse 2 · L1 | B1 后绕球场左、上、右三侧，短折后进入手机庭院；空间继续开阔。 | 前瞻从球场上沿过渡到右侧出口；P4 伴奏回落时球门、矮墙依次升起，运动场线条用低对比度。 |
| 06 Pre-chorus 2 · L1 | 手机形屏片围成狭长单通道；E1 放在场外可见矮架。 | 收近约 10%，前瞻向南；P5 在一句人声收尾时手机无声翻盖，主路上的节奏信息保持清楚。 |
| 07 Bridge · B2/R2 | 长 L 形升层桥，L1 → L2；桥外留空，出口 CP2。 | 先看见完整桥面，再缓慢抬高；P6 第二轮抬升段提前展开承重板，展开结束后玩家才进入。 |
| 08 Final chorus · L2 | 宽视野的不对称马蹄／台阶构图，长直线间插入两组短切分偏移。 | 拉远约 20%，向西前瞻；P7 面板按乐句轮流翻开，五柱群舞回归；最后一句恢复安静留白。 |
| 09 Outro · L2 | 一条舒缓直道接终点方台，CP3；小白兔作远景回声。 | 停止横向摆动，轻微拉远；P8 最后声部消退时兔子与面板定格成蓝白封面构图。 |

**音乐结构说明：** 蓝图保留 Verse 2、Pre-chorus 2，Final chorus 指末轮副歌及其尾部。07 的 Bridge 是第二轮抬升中的**空间桥接段**，不主张原曲另有独立的传统 bridge。没有拿 MV 剧情时长替代歌曲音轨；P1–P8 按乐句锚点对齐，不虚构精确时间码。

**高度与皇冠：** 建议 L0 = 0、L1 = +3、L2 = +6 个方块高度；R1、R2 连续缓坡，每升 1 单位至少留 10 单位水平距离。B1 同层，B2 升层。CP1 位于第一轮副歌出口，CP2 位于终段入口，CP3 位于终点；皇冠平台略放宽。蓝图上的装饰楼梯不属于可走路线。

## 彩蛋与可读性

E1 是第二轮预副歌手机庭院外侧的翻盖手机：经过时屏幕依次点亮五个小色块，完成终段后回看可见一只白兔。沿正常主路即可看见，不要求分叉或离开道路；手机无音效，不干扰节拍。图中黄色篮球还可保留为较容易发现的小细节。

建议中等难度：道路常宽约 **2.8 倍玩家方块宽**，短切分段不少于 2.4 倍，皇冠台约 4 倍。主歌以整拍、半拍和较长直线建立节奏；副歌才引入少量连续半拍／切分转弯，两组密集转折之间安排长直道。每次转向只切换两个世界轴方向，升层不引入跳跃操作。

镜头始终展示至少三个未来转弯；可走路面提前约两小节完整出现，场外景物再做升起表演。柜体和折叠面板不能挡住转角，阴影不压住路沿。宝石放在主路直线上，皇冠是实体存档物件；都不拿来标记点击时机。蓝图上的文字、描边、网格只用于制作说明，游戏画面不显示。
