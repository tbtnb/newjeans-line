# Cookie — Blue Hour Studio / 蓝调折叠舞台

《New Jeans》首张 EP（2022）的《Cookie》关卡参考。以克制的 R&B 律动、黑白长凳舞台和蓝白兔子封面为骨架：窄廊压缩空间，副歌展开悬浮舞台，桥段提高节奏密度，最后显露兔子浮雕。两张 PNG 均使用内置 imagegen 生成；生成提示保存在 [references/generation-prompts.md](references/generation-prompts.md)。

## 简短考据与取舍

- **Dancing Line**：参考经典《The Piano》的象牙白几何平台、橙色实体尾迹，以及《The Autumn》的低多边形布景、俯斜镜头和沿路展开的场景。沿用单方块、窄路、直角转向、宝石与三皇冠语法；不照搬其具体路线。[经典画面与 2017 年报道](https://www.elespanol.com/elandroidelibre/aplicaciones/juegos/20170505/dancing-line-nuevo-musical-creadores-piano-tiles/213729439_0.html)；[The Desert 布景/换色资料（社区整理）](https://dancingline.fandom.com/wiki/The_Desert)。
- **歌曲**：柔和、轻盈且带切分感的 R&B/pop，桥段有 Jersey club 节奏。歌词围绕制作、邀请品尝与吸引注意的 cookie 隐喻；其双关解读曾有争议，ADOR 则解释为送给歌迷的音乐礼物。本关选取“制作音乐、递出礼物”的叙事。[曲风与背景资料](https://en.wikipedia.org/wiki/Cookie_(song))。不逐字引用歌词。
- **MV**：黑色长凳、五人队形、阶梯、留白的摄影棚、蓝紫背景，以及涂鸦 CD，转译为建筑和布景表演。[HYBE 官方 MV](https://www.youtube.com/watch?v=VOmIplFAGeg)；[官方 Weverse 发布页](https://weverse.io/newjeansofficial/media/1-107783732)；[同期布景报道](https://www.allkpop.com/video/2022/08/newjeans-signals-the-release-of-their-debut-ep-with-mv-for-rb-inflected-single-cookie)。
- **实际封面**：采用 2022 首张 EP 的蓝白网点兔子、鼓起的脸颊和伸臂轮廓，转译成终段浮雕与方形网点墙。[官方唱片页及封面](https://www.newjeans.jp/discography/kidbwk)；[Apple Music 专辑信息](https://music.apple.com/us/album/newjeans-1st-ep-new-jeans/1635469682)。不是 2023《Get Up》的飞天小女警或兔子阵列。

研究采用聚合网页搜索与 YouTube/Weverse、官方唱片网站、Apple Music 定向回查，不能指定多个搜索引擎时以这些平台交叉验证。已下载并目视核对的封面、MV 截图及游戏画面见 [research-sheet.jpg](references/research-sheet.jpg)；部分原始图片地址失效后改用可访问的官方封面及同期截图。MV 画面判断来自截图与同期描述，不声称逐帧审片。

## 路线、镜头与音乐事件

蓝图编号为顺序，不是百分比。保留第二轮主歌/预副歌/副歌，合并画在 **05 REPRISE** 内。L0/L1/L2 分别为设计相对高度 0/3/6 路宽单位；B1/B2 为桥。概念图是 **07 终副歌** 的游戏视角，背面可以回望长凳和 CD。所有路线都是连续路面；布景台阶不要求玩家跳跃。

| 区域 | 路线与空间 | 镜头 | 音乐同步表演 |
| --- | --- | --- | --- |
| 01 Intro / L0 | 长直入场，两个错位弯；窄黑景片形成封闭入口 | 俯角约 58°，方位约 45°；中近距离 | E1：低音进入时两侧景片依次升起；让第一处弯先可见 |
| 02 Verse 1 / L0 | 不对称方 S；长—短—短句式，沿五席长凳穿行 | 固定方位，略靠近；前看至少两个转角 | 人声句末触发路外座席嵌片轻抬，呈现五人呼应 |
| 03 Pre-chorus 1 / L0→L1 | 三段错台折线与连续坡道，空间逐步打开；B1 接下一区 | 在长直道缓慢拉远，保持转向轴一致 | E2：五级阶台在上行乐句逐块展开；桥面提前完整显露 |
| 04 Chorus 1 / L1 | 开阔舞台，方形马蹄路线；一长边配短角组；出口 CP1 | 扩大视野，CD 留在路线外侧 | E3：副歌首拍侧翼摊开、CD 景片倾起；背景由灰蓝转钴蓝 |
| 05 Reprise / L1→L2 | Verse 2 压缩偏移窄廊 → Pre 2 错台上坡 → Chorus 2 再次扩展成矩形露台 | 每个长句间调整距离，第二副歌比第一次更远 | E4：复现长凳/侧翼母题但移到高一层；随和声增加景片，不靠增加盲弯制造升级 |
| 06 Bridge / L2→L1 | 2+1+2 组间距不等的短折线，接一条释放直线；CP2；B2 连续上坡至 L2 | 先轻推近，再于释放直线拉远 | E5：成对阶台响应 Jersey club 鼓组交替起落；高频细碎音交给布景，转向只跟选定主节奏 |
| 07 Final chorus / L2 | 长桥引入宽 L 形舞台，兔子浮雕揭幕；EE 在安全长直道的侧向视野 | 保持三分之四俯视，缓慢拉远约 15%，让兔子和下一弯同时可见 | E6：兔子墙的矩形板块按乐句拼合；五个座席阴影在此短暂组成兔子轮廓 |
| 08 Outro / L2→L0 | 连续下降坡，长直收束，仅最后一弯；CP3/END | 在坡顶完成调整，此后稳定跟随 | E7：最后乐句景片向外折下，留白增多；尾迹保留，收尾皇冠在余音中落定 |

此处是音乐段落与事件设计，不是音频实测节拍谱；未提供本地音频，故不编造精确秒数、BPM 或转向总数。制作时先按正式发行音源的乐句边界校准，再以波形/听感确定每个拐角。景片动作以小节或乐句驱动，玩家转向谱独立编排。

## 彩蛋、难度与读路

- **EE 五席兔影**：07 的安全长直道旁，五席长凳的几何投影在特定镜头角度拼成封面兔子；可加一枚小饼干形“光盘压片”作为原创细节。自动经过即可发现，无支线、无额外点击，不影响满冠。
- 难度定位中等偏上：前段练习乐句式长短转角，第二轮改变间距，桥段达到密度峰值，终副歌以开阔视野释放压力。主要使用 1/4 与 1/8 节奏选择，不将所有 hi-hat 转成点击。
- 玩家方块宽为 1，普通路宽约 3，桥段最窄建议 2.6；弯前至少预览两个转角/约两拍。所有转向保持 90°，镜头大幅调整放在长直道，禁在密集拐点突然旋转。
- 皇冠三处：CP1 第一副歌出口；CP2 桥段释放直线；CP3 终点。蓝图中的宝石表示候选位置；实际制作筛选为十颗，分配建议 1/1/1/2/2/1/1/1（01→08）。放在既有主路安全位置，不用宝石引导误判岔路。
- 道路及转角先生成，路外布景可随后表演；桥、坡和下一弯至少提前两拍可见。升降景片不遮挡路面，不从玩家视野前景穿过。
- concept.png 无操作提示圈、箭头、引导线和 UI 文字。blueprint.png 按 01→08 阅读，标签和地标引线只用于设计图，不进入游戏；蓝图是美术构图参考，实际碰撞与节拍以实施路线数据为准。
