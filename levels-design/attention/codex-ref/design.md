# Attention — 夏日目光

为 NewJeans 首张 EP《New Jeans》（2022）的《Attention》设计的 Dancing Line 同人关卡。主线是一次由近到远的靠近：屋顶庭院 → 悬桥 → 开放球场 → 再次收拢的窗廊 → 留白长桥 → 双耳展廊 → 封面广场。

- `concept.png`：第一副歌附近的游戏内视角；珊瑚红方块与实体线尾、象牙白道路、展开中的球场看台、远处蓝白兔子浮雕。无点击提示、箭头、辅助线或 UI 文字。
- `blueprint.png`：俯视总图，按 01–09 顺序行进；红色细线只在蓝图中表示设计路线。图中三层高度、两座桥、三皇冠、十颗宝石、P1–P5 演出与 E1 彩蛋均有标记。

## 简要研究与转译

**Dancing Line。** [猎豹官方介绍](https://cheetahgames.cmcm.com/DancingLine?hl=en)强调听节拍与旋律、穿过不同情绪的世界。结合 [2017 年《The Piano》实机截图](https://www.elespanol.com/elandroidelibre/aplicaciones/juegos/20170505/dancing-line-nuevo-musical-creadores-piano-tiles/213729439_0.html)、[《The Autumn》截图](https://apprecs.com/ios/1177953618/dancing-line-music-game)与[《The Desert》关卡资料](https://dancingline.fandom.com/wiki/The_Desert)，提取高位斜俯视、单方块和持续实体线尾、窄路与大块色域的关系。《Piano》的物件尺度、《Autumn》的几何植物和遮挡节制、《Desert》的场景升起与色彩切换，转为本关的看台展开与蓝白封面揭幕。皇冠和宝石作为世界中的物件保留。

**歌曲与 MV。** [官方曲目页](https://www.newjeans.jp/discography/kidbwk)确认 EP 于 2022-08-01 发行，《Attention》为第一曲。[歌曲资料](https://en.wikipedia.org/wiki/Attention_(NewJeans_song))描述其流行/R&B 与世纪之交的律动；[发行歌词](https://www.genie.co.kr/detail/songInfo?xgnm=97582506)围绕心动、犹豫和渴望得到对方注意。美术读法是清爽、松弛、略有紧张的夏日靠近，节奏变化用空间开合表达。[官方 MV](https://www.youtube.com/watch?v=js1CtxSY38I)及其[舞蹈版](https://www.youtube.com/watch?v=x8RIixqumUc)提供绿茵球场、看台、运动服和共同出游的视觉锚点；[同期报道](https://www.nme.com/news/music/newjeans-attention-debut-single-music-video-ador-hybe-3274591)确认西班牙街巷与少女结伴的叙事。

**实际封面。** 已直接查看[官网封面原图](https://officialsite.cds-jp.online/migs/newjeans/media/E2GSDh/ywkuru2a2w.jpg)：蓝白网点、笑脸大眼兔、伸展双臂、下方 NWJNS 字样。关卡提取蓝白色域、兔脸与双耳轮廓，字标不进入游戏画面。没有采用 2023《Get Up》或《New Jeans》单曲的飞天小女警视觉。

## 分段、镜头与演出

七类空间母题展开为九段，保留重复主歌／副歌。**图上的 BRIDGE 是关卡过渡名称，对应第二次预副歌附近的人声衔接，不宣称歌曲另有独立桥段。** 以下是音乐触发设计，尚非逐拍谱面；落地以正式发行音轨对齐，不使用叙事 MV 含片头的播放时间。

游戏镜头统一采用近正交 3/4 斜俯视，俯角约 55°、偏航约 45°。保持同一世界朝向，沿路平移；表中的方向指镜头追踪方向。图上方为北，蓝图本身为垂直俯视。

| 段落 | 环境与路型 | 镜头追踪 | 音乐同步事件 |
|---|---|---|---|
| 01 Intro | L0，小屋顶、两段长直线与一个大 L，留白起步 | 北移，较近 | 初始节奏显露窗框；首个拐点对应清楚的乐句重音。 |
| 02 Verse 1 | L0，两个不等长庭院凹湾，空间收窄 | 北移，固定朝向 | P1：屋顶块按乐句逐个升起；布片轻摆，转点跟随主要人声句法。 |
| 03 Pre-chorus 1 | L0→L1，错位阶梯形平面、连续缓坡、B1 长悬桥 | 先北后东，轻拉远 | 和声增加时桥侧块依次展开；桥面先完成，再允许玩家进入。 |
| 04 Chorus 1 | L1，沿球场三边的大 U，空间骤开 | 南→东→北，拉远约 15% | P2：第一副歌入口看台外翻、三块顶棚依次抬起；出口 C1。概念图取这一带的局部。 |
| 05 Verse 2 | L1，连接桥后进入不对称方折 S 廊，再收紧 | 经东向连接后向南，缓慢推近 | 窗格按人声短句显现，已出现的建筑保持稳定。 |
| 06 Bridge / Pre 2 | L1→L2，B2 长直虚空桥，末端单肘折 | 南移，平滑抬高 | P3：布片在乐句末轻抬；长音期间触发 E1，降低转向密度让视线停留。 |
| 07 Chorus 2 | L2，偏角矩形长廊，两侧平台打开 | 南→西，拉远 | P4：三块场景平台向外扇开；出口 C2，下一段先完整可见。 |
| 08 Final chorus | L2，两段高低不一的长矩形耳廊串联 | 向西推进，随南北折返平移 | P5：兔子浮雕从蓝色块阵中逐排显出；重复副歌保持可辨认的节奏组，耳廊不形成岔路。 |
| 09 Outro | L2，一条舒展长路加末尾 L，落到封面方台 | 西移，缓慢拉远并停止 | 结尾逐字人声可对应场外方块依次翻白；最后落点收下 C3，尾音只保留线尾和蓝白兔子。 |

L0 / L1 / L2 为相对高度 `0 / +4 / +8`，单位是美术网格。B1、B2 跨越虚空，均为连续缓坡；没有跳跃、断桥或需要选择方向的交叉路口。冠台比普通道路稍宽。

## 彩蛋、难度与可读性

**E1「五扇窗」。** 位于 06 长桥外侧小墙，五扇琥珀色窗在一处长音依次点亮，再同时熄灭，呼应五人共同出游与希望被看见的主题。这是本关创作的彩蛋；无支线、无需偏离道路，也不要求额外操作。

- 主路宽约为方块的 3 倍，连续实体线尾与方块同宽；全关为单路，转向为世界坐标 90°。图中连线的圆滑接头仅是蓝图绘制效果。
- 难度从长乐句转向 → 主歌错位长短句 → 副歌组合转向渐进；末副歌复用已有节奏语汇，不能用每个鼓点都拐弯的方式堆密度。
- 始终让未来约三个转角可见；场景演出至少提前两拍开始，关键路面提前一整乐句显露。看台、兔子碑和窗墙都退到道路外侧，不能遮住方块或下一个转角。
- 宝石放直线，不用宝石暗示转弯时机；C1 在 04 出口，C2 在 07 出口，C3 在终点。蓝图十颗宝石只是收藏位置草案，转点与收集碰撞仍需随音轨校准。
- 只在段落长直线处缓慢改变缩放与高度；不在短转向组里旋转镜头。换色先发生在远景，保持象牙白路面／红线的稳定对比。
- 概念图严格禁用点击圈、箭头、节拍点和 UI；蓝图上的细红线、编号与引线只供制作使用。
