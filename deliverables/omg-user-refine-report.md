## 3. 怎么确定每个点对的是哪个音

- 候选：偏移校正后的点 ±120 ms 内所有的 1/16 格位。
- 证据：每个格位附近最强的真实起音。kick/snare/贝斯/合成器 ±30 ms；人声分轨的起音和歌词对齐的音节 −50..+35 ms（起音是辅音开始的时刻，比听感上的拍点 p-center 早一点）。权重：kick/snare/人声/音节 1.0，贝斯/合成器 0.8；在混音里被盖住的（比整体低 14 dB 以上）×0.3。
- 选择：Viterbi 动态规划。代价 = 位置误差（σ 30 ms）− 3 × 证据 + 1/16 反拍惩罚（有真实起音时 2，没有时 8）+ 和用户自己相邻点间隔的误差（σ 30 ms）。格位严格递增，所以不会合并，也不会凭空加点。
- 空格位检查：如果一个点所在格位没有真实起音（< 0.35），而相邻 1/16 或 1/8 格位有强起音（≥ 0.6），并且离校正后的点不到 75 ms，就把它挪过去。这次 0 个点满足条件（第 6 节）。
- 人工复核：自动结果和 v1 不同的地方，以及 v1 标记的 23 个可疑点，逐个对照歌词时间、点的间隔、前后点来判断。
- 最终时间就是网格时间（127.003 BPM，beat0 0.011）。这个网格和鼓是对齐的：snare 起音相对网格的中位偏差 0 ms，贝斯 +3.6 ms，人声 +3.1 ms。所以点在网格上，听起来也就在音上。

v2 每个点到它对应起音的距离：中位 2.4 ms，90% 在 19.7 ms 以内（351 个点有起音可比）。
